# Figures

The default plotting command generates the chronology of recorded approach mentions across four publication periods. It uses all 139 included publications as denominators; 62 name at least one selected approach.

| File | Role |
|---|---|
| [technology-timeline.pdf](technology-timeline.pdf) | Current vector figure |
| [technology-timeline.png](technology-timeline.png) | Current image preview |
| [manifest.json](manifest.json) | Input, environment, and output fingerprints |
| [synthesis-processing-costs.pdf](synthesis-processing-costs.pdf) | Historical illustration covering two studies |
| [synthesis-processing-costs.png](synthesis-processing-costs.png) | Historical illustration preview |

The historical illustration uses different tasks and measurement conditions. It does not support a collection-wide performance ranking and is not regenerated by the default command. Use the optional command and separate destination documented in [REPRODUCE.md](../../REPRODUCE.md).

The five numerical trace tables and the matching rules are described in the [plot method](../sources/revisao/technology-timeline-method.md). Figure binaries may vary across rendering environments; numerical records must agree exactly.
